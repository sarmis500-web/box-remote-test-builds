The TV app shows these buttons itself. On the TV the app is called Box Remote Agent. Then follow the TV until it says your phone can control this box.

4

Activate the box

  • Code from your seller
  • boxremote.sarmis500.workers.dev/redeem
  • Code + TV code
  • Activate this box

Only if the TV says This box isn't activated. Ask the person who sold you the box for an activation code. Then open the address above on your phone, type that code and the TV code the TV shows. The TV unlocks within a minute.

5

Connect your phone

  • Same Wi-Fi
  • Open Box Remote Buddy
  • Tap your box
  • Type the 4-digit pairing code

The phone finds the box by itself, and the TV shows the 4-digit pairing code. If the phone asks to Allow a connection, tap Allow. That's it: your phone is the remote.
