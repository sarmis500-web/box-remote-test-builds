Box Remote · Venue · for Cody

Control every TV box in the bar from one screen

Works with the vSeeBox V6 Pro, V6 Plus, V5, V2 and Elite. Nothing to install on your computer or phone — the dashboard runs in a browser. One box is enough to try it (about five minutes); every box after that is steps 1 and 2 plus one click.

Want to see it before touching a box? A look-only demo with six pretend TVs: sarmis500-web.github.io/box-remote-test-builds/venue-preview.html (opens on your phone too).

What you need

The boxesPlugged in, on the venue's Wi-Fi, with their own remote working (setup takes a few presses).
Your Gmailvseeboxsales@gmail.com is already on the tester list — sign the box's Play Store in with it (or install with Downloader, step 1).
A screen to run it fromAny computer or tablet on the same Wi-Fi as the boxes. A browser is all it needs.
Your license keyIt is in step 4 below — paste it once. Good through December 1.

Setting up a box

  1. On a computer (laptop or desktop)

    Install "Box Remote Agent" onto the box from Google Play

    On a laptop or desktop computer (not on the box, not on a phone), open play.google.com/apps/testing/com.vbr.boxagent, signed in as vseeboxsales@gmail.com, and click Become a tester. Then click Install (or Install on more devices) and pick the box from the device list. If several boxes are listed, run Install once for each. It lands on the box in about a minute — open the box's Play Store if it is slow.

    No computer handy? On the box: open Market, install Downloader, and in Downloader type tinyurl.com/2b6k4yna → Install → Open. On a V6 Pro or V6 Plus, Android then blocks the switch in step 2 until you go to Settings → Apps → Box Remote Agent → the ⋮ menu → Allow restricted settings.

    Once Google makes the app public (expected early October) this whole step becomes: on the box, open the Play Store, search Box Remote Agent, Install — that is what bar owners will do.

  2. On the box

    Open it and flip the switches it asks for

    Press I understand — continue and turn on the Box Remote Agent switch on the Accessibility screen. Android warns that the app can see the screen and press keys — that is exactly its job; choose Allow. The app comes back by itself.

    V5, V2 and Elite boxes show two more switches (Android calls the app a keyboard — that is how it presses buttons for you). Flip them the same way.

    When the screen says All set, the box is done. Open Box Remote Agent again any time to get back to that screen.

  3. On the box, then your computer

    Press "Venue dashboard" and open the address it shows

    The TV shows an address of its own — yours will be different — like http://10.0.0.57:8484/venue plus a QR code. Type the address into a browser on the computer, or scan the code with a tablet.

    That page is the dashboard. Bookmark it and keep using that same address; every box has one, but your license and TV list live with the address you set up.

If something looks wrong

  • A card says "Service off" and Home, Sleep and the app buttons are grey. The box lost power and forgot its switch. Arrows, channels and Back still work. At that TV, open Box Remote Agent with the box's own remote and flip the switch again — the dashboard cannot do it for you.
  • A card is red / "unreachable". The box is off, or on a different Wi-Fi than the computer. Same Wi-Fi is a must.
  • Scan finds nothing, or misses a box. That box has not finished step 2 yet — the app has to be switched on before it can be found. Or the computer is on a different Wi-Fi (a guest network, a phone hotspot). You can also press Add by address and type the address off that TV.
  • A card asks for a 4-digit code. The license has not been pasted yet — paste it. (Or press any key on the card and type the code the TV shows; that pairs just that one TV.)
  • The bookmark opens an empty dashboard, or asks for the license again. You opened a different box's address, or the router gave the box a new one. Press Venue dashboard on the box you set up with and use the address it shows now; paste the license again if it asks.
