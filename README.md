# Box Remote — test builds

Time-limited test builds of Box Remote, a phone remote for Android TV boxes (works with vSeeBox models).
Every build here expires on the date in its release title and then stops working. Not for resale.

The main install route is the Play Store closed test (both apps); the landing page at https://sarmis500-web.github.io/box-remote-test-builds/ carries the links. The files below are the direct-download fallback.

Files in each release:
- `boxremote.apk` — install on the TV box.
- `boxremote-phone.apk` — optional, for Android phones. iPhone users open the address the TV shows in Safari.
